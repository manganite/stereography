# Sicherheit

Die App ist eine statische Webseite ohne Server, Konto oder Übertragung von Daten; Einstellungen und Fortschritt im Quiz bleiben im Browser. Unterstützt wird jeweils nur die neueste Version (die Live-Seite auf GitHub Pages).

## Eine Sicherheitslücke melden

Bitte **nicht als öffentliches Issue**. Stattdessen im Repository unter **Security → Report a vulnerability** eine private Meldung anlegen ([Anleitung](https://docs.github.com/de/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). Hilfreich sind die betroffene Version (steht in der App unten), Browser und Gerät sowie die Schritte, mit denen sich die Lücke zeigen lässt.
